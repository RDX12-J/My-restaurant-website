# Restaurant Website

A restaurant website built with React, TypeScript, Vite,
Tailwind CSS and Supabase.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase

## Local setup

1. Copy `.env.example` to `.env`.
2. Add your Supabase project URL and anon key.
3. Run `npm install`.
4. Run `npm run dev`.
